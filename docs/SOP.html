Text Revival Campaign

How to run the lead-texting automation — from installing the app to saving the daily report.

Document: Operating Guide Applies to: Revival AI desktop app & web dashboard Audience: Campaign operators

1.  Overview — what the tool does

Revival AI works your leads for you. You load a list of leads and press Start; the tool then handles every lead the same way, automatically — searching, checking the rules, sending the correct approved message, and recording the outcome. You never type a message or decide who to text.

For each lead, the tool performs the following steps in order:

  1. Find the lead in REI. It searches REI BlackBook by property address, owner name, or phone number and opens that contact.
  2. Check that it is allowed to be texted. Is the property in California? Has it already been texted this month? Is the contact opted out, marked “do not text,” sold, listed, or a wrong number? If any apply, the lead is skipped — no message is sent.
  3. Select the correct message. The tool reads whether the lead belongs to Equity Track (EQT) or Twin Home Buyer (THB) and uses that company's approved message — never the other.
  4. Send and confirm. It sends the approved text, then confirms the message actually went out before marking the lead “Text Sent.”
  5. Record the result. The outcome is shown on the dashboard and saved for the report, so results are accurate and no lead is ever texted twice.
In short You load the leads and press Start. The tool does the searching, the safety checks, the correct message, and the record-keeping — for hundreds of leads — exactly the same way, every time.

2.  Download and install the app

One-time setup, performed once per computer.

Download the installer from Google Drive:

  1. Open the link and download. Open the Drive page, then click the Download button (top-right). Save the file.
  2. Run the installer. Open the downloaded Revival AI Setup file. If Windows shows a blue “Windows protected your PC” notice, click More info, then Run anyway — the file is safe; the message only appears because it is not distributed through the Microsoft Store.

Multiple users Each person installs their own copy from the same Drive link, on any computer or network. All copies operate through the single shared REI account, so runs do not conflict and no lead is texted twice.

3.  Opening the tool and first-time login

Double-click the Revival AI desktop icon to open the dashboard. (On the main office computer, the same dashboard can also be opened in a web browser at http://localhost:3000 while the program is running.)

First run only — log in to REI The first time you run the tool, a browser window opens on the REI BlackBook login page. Log in there once, by hand. The login is remembered afterward, so you will not need to log in again on future runs.

4.  Loading your leads

Choose one of the two options below.

  • Upload a spreadsheet. Click “Choose File” and select your CSV or Excel file. The tool reads your columns automatically and keeps them all.
  • Pull all from REI. Click “Pull all from REI” to bring in every contact directly from REI — no file required.
Leads already worked this month are remembered Any lead worked earlier this month appears with its result already filled in and is skipped, not repeated. Only new leads are worked. This record resets automatically at the start of each calendar month.

5.  Running the automation

Set it up once, press Start, and let it run.

  1. Turn on Live Sending. Click “Live Sending: OFF” so it changes to “Live Sending: ON.” When OFF, the tool checks everything but sends nothing (safe practice mode); when ON, real text messages are sent.
  2. Set the batch size. Set “Texts per run” to 100 and leave “Auto-continue” checked. The tool sends 100, pauses briefly, then automatically continues with the next 100.
  3. Press Start. Click “Start Live Automation.” The tool works down the list on its own and keeps going, batch after batch, until every lead is finished or you press Stop.
  4. Monitor progress. The summary cards and the table update live as leads are worked. Links open the contact in REI or the property on Redfin for a quick check.
  5. Stop when finished. Click “Stop” to end your shift. Progress is saved; the next time you press Start, it resumes the unfinished leads and skips those already completed.

7.  Automatic safety rules

These rules are always enforced. No action is required from the operator.

  • California only. Any property outside California is skipped as Out of State.
  • Never twice in one month. A lead already texted during the current month is skipped.
  • Correct company every time. The tool determines whether the lead is EQT or THB from REI and sends that company's message. If it cannot determine the company, it holds the lead rather than risk sending the wrong message.
  • Opt-outs and blocking tags respected. If REI indicates the contact is opted out or should not be texted, no message is sent.
  • Accurate “Text Sent” status. A lead is marked “Text Sent” only when delivery is confirmed. If a send cannot be confirmed, it is held for another attempt and never falsely marked.

8.  The daily report

At the end of a shift, click “Daily Report.” The report opens inside the tool and shows two sections:

  • Today — only the leads worked today (the shift's numbers), with a short summary line.
  • This Month so far — the running total for the entire month.

Use “Save Today” or “Save This Month” to download a clean, one-page PDF report. It saves directly to the Downloads folder; no printer is required.
